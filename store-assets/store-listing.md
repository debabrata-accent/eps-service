## Full description (max 4000 chars)
```
EPS Service is a service-management platform for electrical panel maintenance. It connects factory owners with a team of specialist engineers, coordinated by a customer executive, so panel faults get resolved quickly and transparently.

WHO IT'S FOR
• Factory Owners — raise service tickets with full fault details, photos, videos, and design documents. Track status live, approve quotes, and pay the advance securely.
• Customer Executives — review incoming tickets, propose service costs, collect advance payments, and release approved jobs to the engineer pool.
• Specialist Engineers — get notified when new approved jobs are available, self-assign work on a first-come-first-served basis, update job status step by step, and file service reports.

KEY FEATURES
• Create detailed service tickets with fault images, videos, and design documents
• Live ticket status tracking from submission to completion
• Transparent cost quotes with in-app approval
• Secure advance payments (UPI, cards) via Razorpay
• First-come-first-served job assignment for engineers
• Step-by-step work status: Assigned, Visited Factory, Issue Identified, Solution Proposed, Issue Fixed, Completed
• Role-based access — each user sees only what's relevant to them
• Reports and history for owners, engineers, and administrators
• Push notifications for new jobs, quotes, payments, and status updates

Secure, role-based, and built for real electrical service workflows.
```
